# 多模态AI周报 — 反馈闭环规则

## 规则说明

每期周报末尾包含反馈入口，读者可以提交对事件分级、分类、权重的修正意见。
系统在下次运行时自动读取最近4周的反馈，注入AI Prompt以改进输出。

## 反馈文件格式

在 `feedback/YYYY-WNN.md` 中提交：

```markdown
- [x] 事件标题: 正确分类为 #video-gen（理由: 核心是视频生成新架构）
- [ ] 事件标题: 应该降权，只是营销发布没有实际能力展示
- [x] 事件标题: 遗漏了关键数据——推理速度实际提升3倍而非2倍
- [x] 事件标题: 应补充标注模态为 👁️+🎨 而非仅 #vision
```

## 标记含义

- `[x]` = 已确认的永久规则，每次都注入 Prompt
- `[ ]` = 待确认的建议，人工审核后再标记为 `[x]`

## 自动注入的 Prompt 内容

下次运行时，已确认的反馈会自动生成为 Prompt 节选：
```
## 反馈修正（来自上期读者）
- 上周"FLUX 3 发布"应归类为 #image-gen + #omni，不仅 #image-gen
- 目前读者更关注: 全模态统一架构 > 视频生成 > 图像生成 > 语音
- 对评测分数需要注明评测集和对比基线，避免裸数字
```
