### DeepSeek V4 多模态模型发布 OpenAI 风格 API 适配器
🏷️ #omni #industry · ⭐ 6

**一句话：** DeepSeek 为其强大的多模态模型 DeepSeek V4 推出了一个适配器，让开发者能像使用 OpenAI API 接口标准一样方便地调用它，降低了集成门槛。

*   **发生了什么：** FanFPu 团队为 DeepSeek V4 多模态模型发布了一个本地运行的 API 适配器 (deepseek-responses-bridge)。
*   **为什么重要：** DeepSeek V4 本身是一个强大的多模态模型，但其对话补全 API（Chat Completions API，这是大型语言模型常用的接口）与 OpenAI 的响应式 API（Responses API，一种常见的模型输出接口标准）有所不同。这个适配器解决了兼容性问题，允许依赖 OpenAI API 格式的现有工具和应用无缝切换或集成 DeepSeek V4，极大地方便了开发者和生态系统的拓展。
*   **关键数据/能力：** 该适配器在本地 `127.0.0.1:8787` 运行，能将 DeepSeek V4 的 Chat Completions API 转换为 OpenAI 风格的 Responses API。
*   **模态标记：** 🔄全模态
